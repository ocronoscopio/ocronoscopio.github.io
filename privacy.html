Privacy Policy

This policy covers this website and O Cronoscópio Publisher (the "API Client"), the private tool used to publish videos to the O Cronoscópio YouTube channel and to its Instagram account.

1. Who we are

O Cronoscópio is a science-communication channel run by an independent creator in Brazil. Contact: ocronoscopio@gmail.com.

2. Use of YouTube API Services

The API Client uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics API). By using any feature that relies on YouTube, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The API Client is not a public product. It runs only on the creator's own computer and is authorized, through Google OAuth 2.0, only by the owner of the O Cronoscópio channel. No other user can sign in to it.

The API Client does not access data from any other YouTube account or channel beyond public search results and public comments posted on our own videos.

4. Use of Meta and Instagram APIs

The API Client also uses the Instagram Graph API provided by Meta, through a Meta app with the same name, to republish the channel's own Shorts on the @ocronoscopio Instagram professional account. It is authorized only through a system user of the channel owner's own Meta business portfolio. Meta's handling of data is described in the Meta Privacy Policy.

5. How data is stored

  • All data is stored locally on the creator's computer. We do not operate a server or database that receives YouTube or Instagram data.
  • OAuth credentials and access tokens are kept in a local folder excluded from version control and are never shared.
  • Data obtained from YouTube API Services is not stored for more than 30 calendar days unless it is refreshed through the API, in line with the YouTube API Services Developer Policies. Analytics reports used for planning keep only aggregated metrics of our own channel.

6. Sharing

We do not sell, rent or share any data obtained through YouTube API Services or the Instagram Graph API with third parties. We do not use it for advertising.

7. Cookies and this website

This website does not set cookies and does not use analytics or advertising trackers. It loads fonts from Google Fonts, which may receive your IP address as part of a normal web request.

8. Revoking access and deleting data

  • Access granted to the API Client can be revoked at any time on the Google security settings page.
  • Instagram access can be removed at any time in the Meta Business Suite settings of the account, or by removing the app in Instagram's settings under Apps and websites.
  • When access is revoked, the local tokens stop working and the related local data is deleted within 7 days.
  • If you commented on one of our videos or Instagram posts and want a reply or your comment data removed from our local records, email ocronoscopio@gmail.com and we will delete it within 7 days. Comments themselves can be deleted by you on YouTube or Instagram at any time.

9. Children

Our content is aimed at a general adult audience and is not made for children. We do not knowingly collect data from children.

10. Changes

We will update this page when our practices change and show the new date at the top.
